# What the guardrails cost in time

Generated by `src/measure_guardrail_latency.py`: the gateway with the stub provider (in memory; streams behind a local uvicorn server, since the in-memory transport only returns a finished response), so the numbers are the gateway's own work on this PC (an i7-6700), not a provider's.

## Overhead per policy (200 requests of about 2 KB, one at a time)

| Policy | p50 | p95 | Added at p50 |
|---|---|---|---|
| none | 1.39 ms | 2.6 ms | +0.0 ms |
| defaults (flag, patterns) | 2.46 ms | 4.68 ms | +1.07 ms |
| strict, no judge | 2.64 ms | 4.18 ms | +1.25 ms |
