# What observability costs per request

Generated by `src/measure_observability.py` on this PC (Intel i7-6700, Windows, Python 3.14): the gateway in memory, the stub provider, no database; 6,000 requests per set-up (3 alternating rounds), medians.

| Set-up | p50 | p95 | Added to p50 |
|---|---|---|---|
| metrics only | 1,493 µs | 2,987 µs | (baseline) |
| + request log | 1,648 µs | 3,756 µs | +155 µs |
| + traces | 2,503 µs | 4,785 µs | +1010 µs |

Each piece alone, per call (with a typical request's fields):

- count in the metrics (metrics.observe): 18.57 µs
- format the log line (JsonFormatter): 16.3 µs
- annotate the request span (tracing.annotate): 17.87 µs

For scale: the stub's whole path through the gateway in memory is the baseline above; PostgreSQL adds 30-45 ms per request on this PC (step 7 stage 3), and a real model 0.3 s to a minute.
